# 박상윤 개인 포트폴리오

토목·건설 분야 취업을 위한 반응형 개인 포트폴리오 웹사이트입니다.

## 구성
- `index.html`: 메인 포트폴리오
- `assets/style.css`: 디자인 및 반응형 스타일
- `assets/script.js`: 모바일 메뉴
- `CV.md`: 이력 요약 초안

## GitHub Pages 배포
1. 저장소의 Settings → Pages로 이동합니다.
2. Build and deployment에서 `Deploy from a branch`를 선택합니다.
3. Branch는 `main`, 폴더는 `/(root)`로 선택하고 Save를 누릅니다.
4. 배포가 완료되면 저장소의 Pages 주소에서 확인합니다.

## 게시 전 확인할 내용
- 연락 가능한 이메일 및 연락처
- 자격증의 공식 명칭과 취득일
- 최종 학력 상태 및 졸업 예정일
- 현장실습 회사명과 공개 가능한 업무 범위

현재 문구는 제공된 이력 정보를 바탕으로 작성한 초안입니다. 확인되지 않은 연락처나 자격증 취득일은 임의로 넣지 않았습니다.
